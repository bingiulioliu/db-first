nome repo: `db-first`

Modellare la struttura di una tabella per memorizzare tutti i dati riguardanti delle auto usate messe in vendita da un concessionario. 

Analizzate bene la richiesta per capire quali sono i dati utili (per raccolta informazioni, ricerca, ecc)

Come visto oggi a lezione dobbiamo fornire lo schema (potete benissimo farlo come file Markdown nel README.md) della tabella o delle tabelle, definendo:
- Nome Colonna
- Tipo
- Attributi
- Indici
